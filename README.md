# Practicas_DSM441

Repositorio de guías de laboratorio de la materia Desarrollo de Software para Móviles (DSM441) — Universidad Don Bosco, Ciclo 02-2026.

## Descripción

Este repositorio contiene el desarrollo de las guías de práctica de la materia, implementadas en Android Studio utilizando Kotlin. Cada carpeta corresponde a una guía de laboratorio con su respectivo proyecto y documentación.

Tecnologías utilizadas
Android Studio
Kotlin
XML (diseño de layouts y vistas)
Gradle (Kotlin DSL)
